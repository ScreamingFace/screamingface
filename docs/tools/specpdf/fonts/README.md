# Vendored fonts

IBM Plex Sans and IBM Plex Mono, weights 400/500/600, under the SIL Open Font License 1.1
(<https://github.com/IBM/plex/blob/master/LICENSE.txt>).

They are vendored so `build.py` renders the same faces on any machine. The 2026-09-08 render of
this document depended on a manual install into `~/Library/Fonts` (ledger deviation 3); that
dependency is retired.
