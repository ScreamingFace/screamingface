# Let the Engine start and stop a Run's Candidates itself (E5 P2)

The Engine half of a detached Run. The Engine starts and stops every Run's Candidates itself,
so `sf.evaluate(..., detach=True)` can return at once and its owner can reattach by `run_id`
from any machine.

One PR, five commits (E1 to E5). Spec and plan are in docs PR #1747. `OME-1611` and `OME-1617`
close once the Client PR ships.
