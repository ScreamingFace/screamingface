# Add FutureX-Past as two local Benchmarks (outside contribution, PR 1897)

FutureX-Past, the resolved-question archive of the FutureX forecasting benchmark, served as one
local inspect Task package holding two Benchmarks: `futurex_past` (the FutureX authors' rules,
re-implemented, with the house Judge on levels 3-4) and `futurex_past_study` (a crowd-wisdom
study's own exact-match code, vendored). Both rows are `origin="external"` and name the
contributor.
