# Import the full HLE, pictures included

HLE (Humanity's Last Exam) is 2,500 expert-written questions across more than 100 subjects;
342 (about 14%) carry one picture. inspect_evals ships it as `hle`. Onboarding only; the paid
state-of-the-art run is OME-1672.

- 2026-10-28: Task replay captured all 2,500 Cases with pictures, and the captured messages
  matched inspect_evals' own; the importer refused the scorer.
- 2026-11-02, PR 1 of 2 (#1631): the importer finds a scorer in its own module inside the eval's
  package and reads a judge role passed through a scorer argument from the row's kwargs; the
  gateway judge admits a setting the row pins with the same value.
- 2026-11-02, PR 2 of 2: `hle` imported at `cais/hle` `5a81a4c7`, 2,500 Cases, revision
  `32c089fbfcd9c29f`, licence mit, tier `hard`, policy `withhold`. Judged by inspect_evals'
  maintained `regex_judge` with its primary judge glm-5.3-flash (owner decision 2026-11-02: the
  paper's o3-mini judge is on OpenRouter only as `:batch`). Headline = mean of the judge's
  correct/incorrect; the Candidate's confidence is a second named score. Named deviations: the
  backup judge is not run, and the judge's fp8 pin is not sent. This closes the ticket.
