# Let the Client follow, detach and reattach a Run the Engine drives (E5 P2)

The Client half of a detached Run. The Client sends a Run to the Engine once, with every
Candidate's start, then follows its one event stream and builds the Report from the Engine's
records. `sf.evaluate(..., detach=True)` returns a `Run` at once, and
`sf.runs.get(run_id).wait()` or `.report()` picks it up from any machine.

One PR, two commits (C1, C2), stacked on the Engine PR #1759 (`OME-1895`). Spec and plan are in
docs PR #1747. It merges after the Engine PR is deployed. `OME-1611` and `OME-1617` close when
it ships.
