# Add the pure url4 system fingerprint for E14

E14 in `packages/url4`: the system fingerprint.

- `url4.fingerprint.system_fingerprint()` and `canonical_system_url4()` are pure: no I/O, and only core and stdlib imports (C11).
- `exclude_bindings` drops only inert sources, such as the SDK `_sf_recipe` name. A non-inert source that is excluded raises `ExcludedBindingError`, which the scoreboard maps to 422 `invalid_url4` (D3, Q25).
- 50 golden vectors are shared with the scoreboard parity test (SR-5).

Tests: SR-2..SR-5 and a C11 purity test. The gates are green (coverage 98%, fingerprint.py 100%).
