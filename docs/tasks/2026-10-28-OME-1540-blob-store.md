# Add a content-addressed blob store with upload and fetch routes to the engine

`PUT`/`GET /blob/sha256/<hex>` behind `URL4-Capability`. Each blob is scoped to (tenant, run): the tenant is a
hash of the verified `X-User-Email`, or `anonymous`; the run is the capability token's topic. sha256 is
verified on ingest and on every read (spec #1450 F3). Limits: 8,000,000 B per blob and the five attachment
media types. Storage reuses the filesystem/S3 artifact store under `blobs/`, swept by the artifact TTL.
`ScopedBlobReader` implements #1588's run-scoped `BlobReader` port. Owner design decisions 2026-10-28.

Parent tracker `OME-1681`, epic `OME-1529`. Ledger: `../work/2026-10-28-blob-store.md`.
