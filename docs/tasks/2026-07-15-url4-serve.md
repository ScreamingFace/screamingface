Minimal CLI + HTTP server exposing the `url4` engine as a runnable url4 node, shipped on
`packages/url4` and reusing the existing optional `url4[server]` extra (uvicorn only —
**Starlette is never a dependency**).

`url4 serve` assembles a `Url4Node` from a `url4.toml` config and serves its framework-free
raw-ASGI `asgi()` under uvicorn. The operator declares the node's **whole surface** in that one
file — both halves of an expression:

- **write** — `[commands]` is the only intent-processor kind: operator-owned subprocess argv
  templates (doctrine N4); an LLM backend is the operator's own gateway script mounted as a
  command, and the SDK ships no connector. The argv template mirrors the full `Request` surface
  1:1 — `{intent}`, `{context}`, `{param:<name>}`, `{params}` — substituted in a single regex
  pass, so token-shaped text in caller-supplied values cannot cascade.
- **read** — `[data]` routes back bare relative URIs, `[holdings]` backs `@`, and
  `[identities.<name>]` backs `@name[/collection]`. All three share one provider shape: an
  inline string, or a table with exactly one of `value` / `file` / `command`. `file` re-reads
  per request (edit with no restart); `command` is doctrine N4 applied to reads. `[data]` alone
  takes `media_type`, so a JSON route parses as a collection by declared type, not by sniffing.

The HTTP surface is
GET-only per doctrine N1: `GET {eval_path}?q=<expr>` (default `/v1`), `GET /healthz` (a
`data()` route), 405 on any other method. `--default-route` selects the fan-out reduce route
(explicit must be a declared command; unset → the first declared one; empty `[commands]` fails
fast). A thin raw-ASGI wrapper adds only what the node does not own: 503 backpressure via
`--max-inflight`, a 504 per-request timeout, and graceful node shutdown. Companion
`url4 eval` runs network-free (StaticIOLayer). Streaming, telemetry, and daemonization are
deferred.

Core SDK (same PR, **breaking**): `DEFAULT_PROCESSOR = "/claude"` is removed from `url4.dag`.
An unset `processor` now resolves via the new `url4.io_layer.SupportsDefaultRoute` port
capability to the io world's first declared route (`Url4Node` → first registered endpoint,
`StaticIOLayer` → first `routes` key); with none declared, a fan-out reduce raises a clear
`ResolutionError`. The HTTP wire param `processor=` is unchanged.

**Review round 2 (2026-07-17, PR #402 — Serguey).** Five points, all verified against head and
all upheld. Four were documentation drift with one root cause: each pivot appended a revision
*banner* and left the document body describing the deleted architecture, so the PR description
(copied from the work ledger's first Outcome) still advertised the aigateway connector. The
spec, plan, this mirror, the ledger, and the Linear description have been rewritten against the
code at head; specs state the current target, so bodies are rewritten in place, not bannered.
One point was a real defect: `_LOOPBACK` contained `""`, so `URL4_HOST=` or `--host ""` bound
`0.0.0.0` **and** `::` while both exposure warnings were skipped — fixed, along with the wider
family it belonged to (an empty env var now means unset for every field; `eval_path` is now
validated at all). Release metadata was also silently broken: the `[WIP] feat(url4):` PR title
is not a parseable conventional commit, so release-please would have skipped url4 entirely on
squash-merge.

**Scope extension 3 (2026-07-18, owner-directed).** The node gained its READ surface
(`[data]`/`[holdings]`/`[identities]`) and protocol-param forwarding to commands. Folded into
OME-466 rather than split into a new work item, on the owner's call: a node that cannot resolve
`@` or a bare relative URI does not yet meet this issue's own goal — "the engine as a runnable
HTTP node". Two commits, both additive (no further breaking change). Known limitation recorded
in the spec, then closed: scoped `[holdings]` shelves are addressed by a **path qualifier**
(`GET /v1/science?q=(@)!'…'`, spec §5.6.1/§5.6.3.1), threaded per request via
`ExecutionContext.self_collection`. **It was never a grammar gap** — §5.6.2 fixes
`self-ref = "@"` with no collection suffix, so `@/science` is a parse error by design and the
parser needed no change. `{eval_path}/…` is now reserved: routes declared under it are a config
error, since they would shadow every qualifier below that path.

**Suite hang fixed (2026-07-18).** The item carried for three rounds as "uvicorn test
fragility" was a silent `pytest` hang: two tests asserted the missing-`[server]`-extra branch
while relying on the dev venv to lack it, so with uvicorn installed they called the real
`uvicorn.run()`, bound 4404 and served forever. It looked like a fast `errno 98` failure only
because an unrelated process happened to hold the port. Fixed with a `hide_uvicorn` fixture so
each test creates its own precondition, plus an autouse guard that turns any `socket.listen` in
a unit test into an immediate failure. 796 passed with the extra installed; gates green.
