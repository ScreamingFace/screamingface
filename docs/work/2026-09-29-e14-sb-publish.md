# e14-sb-publish — SB-publish: publish a cache version to GitHub, and admin takedown

## Intent

E14 (epic OME-1307), wave 4, unit SB-publish, in `apps/scoreboard`. The owner of a result publishes
its frozen cache version as a GitHub release (`POST /v1/results/{id}/publish`, C10). A background
worker leases the request, checks the bucket archive digest, and creates the release and its two
assets through the `ReleasePublisher` port (C7). An admin takes a publication down
(`POST /v1/admin/results/{id}/withdraw`), and the worker deletes the release and the tag. The core
is pure (state machine, eligibility, backoff, release body); GitHub and the bucket sit behind ports
with adapters. No migration.
Plan (the full spec): `docs/plan/2026-09-29-e14-reproducible-submission/SB-publish.md`.
Build on branch `unit/SB-publish` (D1): no PR, no Linear issue, no merge gate.
