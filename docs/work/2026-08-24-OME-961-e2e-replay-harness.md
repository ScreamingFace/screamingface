# OME-961 — Run a benchmark end-to-end in CI from recorded responses, with no paid calls

## Intent

Build the e2e replay harness for the SDK package: boot the real aigateway (Postgres via
testcontainers, cache snapshot pre-loaded through the merged OME-951/952 admin route,
ZERO provider keys) plus the real engine app pointed at it, and drive one board through
the notebook-shaped SDK path (`sf.evaluate(...)` → engine → grade → aggregate → report)
against recorded responses. Deterministic and free by construction — a cache miss is a
loud error, never spend. Covers parent OME-956 requirements R1 (whole pipeline like a
notebook), R2 (deterministic + free), R11 (expression-SHA link check) and the harness
half of R5 (judge replays through the same seam as candidate calls).

## Architecture decisions (researched, then fixed)

1. **Boot mechanism: subprocess-per-app from each app's own uv venv** (the `just
   stack-up` idiom), NOT a path dev-dependency + in-process ASGI. Tradeoff: in-process
   (`screamingface._runtime.server._build_apps` already does it) would be faster and
   reuse shipped code, but requires `aigateway`/`screamingface_engine` importable in the
   SDK venv — the dev checkout only gets those via the built wheel's force_include (a
   stale copy) or via path deps that couple the SDK lockfile to both apps' heavy dep
   trees (litellm, tortoise, kubernetes). Subprocess keeps `packages/screamingface`'s
   pyproject untouched except test-only dev-deps (`pydantic`, `testcontainers`), and
   each app resolves its own lock. Gateway: `uvicorn aigateway.main:app` on a free
   port; engine: `uvicorn --factory screamingface_engine.local:create_local_app` (the
   engine CLI hardcodes port 9108, so uvicorn is invoked directly for port isolation).
2. **Clean child environment**: children get PATH/HOME/TMPDIR/LANG only, plus exactly
   the vars the harness sets. A developer's exported provider keys can never leak into
   the stack — spend impossible by construction, verified by the loud-miss test.
3. **Gateway env** (from `config.py` + the OME-952 tests): Postgres URL from the
   testcontainer, `AIGW_AUTH_MODE=disabled` (loopback-only; admin routes answer
   without headers, engine calls anonymously — matches local-stack precedent),
   `AIGATEWAY_ADMIN_EMAILS=<role address>`, `AIGW_REQUEST_CACHE_ENABLED=true`,
   `AIGW_OPENROUTER_ENABLED=true` (participation gates cache READS too),
   `AIGW_DISCOVERY_ENABLED=false` (no catalog egress). NO provider keys, no secrets.
4. **Engine env**: BOTH `URL4_CLOUD_AIGATEWAY_BASE_URL` (App half: catalog/connections)
   and `AIGATEWAY_BASE_URL` (run half: actual model calls) — they are read by different
   halves; setting one is the classic mis-boot. `URL4_RUNNER_CONFIG` explicit;
   `URL4_BENCHMARK_ASSETS` only for board tests.
5. **Markers/gates**: pytest marker `e2e` (registered in pyproject) + runtime gate
   `SCREAMINGFACE_TEST_E2E=1` + docker probe — mirroring aigateway's `needs_postgres`
   + `AIGW_TEST_PG=1` convention. Default lane collects everything, runs the pure
   contract tests, and skips the stack tests loudly with the exact reason.
6. **Synthetic fixture is generated by the gateway's own code**: `key_hash` embeds the
   provider projection and two revision constants, so `generate_synthetic.py` runs in
   the aigateway venv and calls `build_global_cache_plan` — never hand-hashing. The
   committed manifest pins `active_cache_revisions()`; when key semantics bump, the
   upload refuses (`revision_mismatch`) and the boot fails loudly telling the reader to
   re-generate — the OME-951 guard doing exactly its job in CI.
7. **Wire contract on a hit (measured)**: the gateway serves the stored payload
   verbatim PLUS its reserved `_aigw` accounting namespace (taxonomy
   `attach_hit_metadata`). Byte-identity proper is a store property (pinned by
   aigateway's own Postgres round-trip test); the harness asserts provider fields
   structurally identical and `_aigw` present.
8. **Golden carries its replay inputs** (`models`, `limit`): without them a golden
   cannot be re-run. Single-model candidates only for now; extending to fusions is a
   deliberate follow-up.

   added.

   to the measured wire contract (see decision 7).

   float round-trip invariant test.

   `screamingface.case_result.CaseStatus` into `goldens.py` (drift now impossible by
   construction).
