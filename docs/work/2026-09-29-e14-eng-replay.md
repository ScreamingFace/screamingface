# e14-eng-replay — engine replay-grant carry and cache-version counters

## Intent

OME-1307 (E14) wave 3, unit ENG-replay. A run carries an opaque replay grant from the start
request `GET /?q=` (header `X-SF-Cache-Replay`) to every AI Gateway chat call (header
`X-AIGW-Cache-Replay`, written last, only by `world/connector.py`). The engine counts the
gateway's version hits, misses and repeated-key collapses and publishes them as three
`cache.version.*` attributes on the closing cache-summary frame. A rejected grant (403
`replay_grant_invalid`) fails the run with a typed permanent error. The engine never decodes
the grant and never logs it.
Plan: `docs/plan/2026-09-29-e14-reproducible-submission/ENG-replay.md`. Test ids RP-11 to RP-15.
Base note: branch is built on `unit/ENG-freeze` (early start); diff base is `unit/ENG-freeze`.
