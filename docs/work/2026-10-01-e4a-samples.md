# e4a-samples — sf.samples(), the duplicate-members warning, and the seed contract pins (OME-1289 unit 6)

## Intent

`sf.samples(model, n)` builds N `Model`s of one route that differ in an integer `seed`, so a vote over
them counts N real answers and not one cached answer N times. A model whose provider denies `seed`
fails in the existing preflight with `PlanningError(code="unsupported_model_parameter")` (decision
D-8, option A), so samples() adds no request and no new code path. A reducer Fusion whose direct
Model members send the same request now warns with `DuplicateMembersWarning`. The engine and gateway
halves are contract pins of behavior that exists today (call seed wins over run seed; seed is in the
cache key; replay is stable; a gateway seed rejection is `upstream_error` + `metadata.source_code`).
