# e4a-samples — sf.samples(), the duplicate-members warning, and the seed contract pins (OME-1289 unit 6)

## Intent

`sf.samples(model, n)` builds N `Model`s of one route that differ in an integer `seed`, so a vote over
them counts N real answers and not one cached answer N times. A model whose provider denies `seed`
fails in the existing preflight with `PlanningError(code="unsupported_model_parameter")` (decision
D-8, option A), so samples() adds no request and no new code path. A reducer Fusion whose direct
Model members send the same request now warns with `DuplicateMembersWarning`. The engine and gateway
halves are contract pins of behavior that exists today (call seed wins over run seed; seed is in the
cache key; replay is stable; a gateway seed rejection is `upstream_error` + `metadata.source_code`).

## User decision U1 (2026-10-01): warn when a run seed meets own-seed calls

- **Rule (engine, unchanged):** a call that sets its own `seed` keeps it; the run's `answer_seed` (one "sitting",
  OME-1038, `X-Answer-Seed`) applies only to calls without one (`request_parameters.apply_answer_seed`). So `samples()`
  members and any `sf.Model(params={"seed": ...})` send the same requests in every sitting, and a mean and CI across
  sittings is falsely tight. **Decision: warn, do not refuse.**
- **Verified:** `Client.evaluate` / `AsyncClient.evaluate` validate `answer_seed` (`_answer_seed_value`) and pass it to
  `runner.evaluate_sync` / `evaluate_async`, which stamp it on each compiled Candidate (`_seeded_candidates`) and send it as
  the `X-Answer-Seed` header (`transport._answer_seed_header`). There is no separate sittings API.
- **Built:** `sf.FixedSeedSittingWarning(EvaluationWarning)` (`warnings.py`, exported, snapshot regenerated). The check
  reads the compiled `Candidate.parameter_assignments` (the data the preflight uses): every assignment whose params hold
  `seed` is an own-seed operation. One warning per Candidate that has any, naming the run seed and the operation ids,
  pointing at the caller's line (`skip_file_prefixes`).
- **Placement:** inside `runner._seeded_candidates` (once per `evaluate_*`, after compile, before the model-details lookup
  and any submit). It is not a separate statement in `evaluate_sync` / `evaluate_async` because both are at the ruff limit
  of 26 statements. Side effect: a preflight refusal can follow the warning.
- **Not covered:** a raw URL4 string evaluated with `answer_seed` (`evaluate_url4_*`) has no compiled assignments, so it
  does not warn.
- **Tests:** `tests/test_fixed_seed_sitting_warning.py` (RED seen first: the four warn cases failed on `len(fixed) == n`,
  the three no-warn cases passed on the skeleton class).
- **Docs:** README (`Independent samples of one model`), CHANGELOG.
