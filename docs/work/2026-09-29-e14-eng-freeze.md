# e14-eng-freeze — engine freeze proxy route (POST /v1/cache-versions)

## Intent

OME-1307 (E14) wave 2, unit ENG-freeze. Add one engine route, `POST /v1/cache-versions`. It takes
a `trace_id` from the SDK, forwards it to the AI Gateway `POST /v1/cache-versions` with the caller
identity, and gives the gateway receipt back unchanged (contracts C2a, C2b). Hexagonal: a core
port `CacheVersions`, an `AigatewayCacheVersions` httpx adapter, a REST router. No engine retry.
