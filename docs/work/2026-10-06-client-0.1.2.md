# client-0.1.2 — Release the ScreamingFace client as 0.1.2

## Intent

Make the Client changes merged after `0.1.1.post9` installable as `0.1.2`, without widening
this manual release bump into source, dependency, or release-automation changes. A clean patch
release off the `0.1.1.postN` line (the prior release was `0.1.1.post9`, OME-1338 / PR #1068).
Publish via the `release-screamingface` workflow once the owner tags `screamingface-v0.1.2`.
Same shape as the postN bumps: version + lockfile only, under a ticket. Note: release-please's
auto PR (#592) proposes `0.2.0` from the feat commits — this manual release deliberately cuts
`0.1.2` instead; #592 is left as-is.

## Planned changes

- `packages/screamingface/pyproject.toml` — version only (`0.1.1.post9` → `0.1.2`).
- `packages/screamingface/uv.lock` — matching local `screamingface` package version (`uv lock`).
- This unit's work ledger and (at PR-open) task mirror.
- Deliberately NOT touched (ungated, matching #1068): `apps/screamingface-studio/runtime/uv.lock`
  (studio is not in release-please and has no PR gate) and the `generated_by_version` output in
  `examples/14_report_accounting.ipynb` (notebook output data, source-only notebook gate).

## Test plan

- `uv lock --check` clean (CI's lockfile-current gate); manifest and lockfile agree on `0.1.2`.
- `tests/test_version.py` passes: `sf.__version__` (installed distribution metadata) equals the
  `pyproject.toml` version after `uv` re-syncs the editable install. No test is hardcoded to a
  version string, so no append-only gate applies.
- Built distribution metadata reports `0.1.2` (`scripts/check_distribution.py`), `uv build` and
  the deterministic notebook check stay green.

## Acceptance

- The installable Client version is `0.1.2`.
- No source, dependency, API, or runtime behavior changes.
- `run_gates.py screamingface` green; `uv lock --check` clean.
- `0.1.2` tagged `screamingface-v0.1.2` by the owner after merge and published to PyPI (publish
  may block on the one-time PyPI Trusted-Publisher owner setup — reported, not worked around).
