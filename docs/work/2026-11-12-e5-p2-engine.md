# e5-p2-engine — E5 P2 Engine: the Engine drives every Run's fan-out

## Intent

The Engine half of E5 P2 (`OME-1837`): the Engine starts and stops a Run's Candidates itself, so
`sf.evaluate(..., detach=True)` can return at once and its owner can reattach by `run_id` from any
machine. Spec `docs/spec/2026-11-04-e5-p2-detached-run.md` and plan
`docs/plan/2026-11-04-e5-p2-detached-run.md` (docs PR #1747). One PR, five commits, E1 to E5.

  refused, so a deployment that set a short grace alone, as P1 allowed, still starts.
