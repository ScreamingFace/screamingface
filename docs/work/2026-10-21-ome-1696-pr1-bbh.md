# ome-1696-pr1-bbh — BIG-Bench Hard as a local Task, asked and graded the paper's way

## Intent

Grantee applicants ask for BBH. Serve all 23 tasks in the paper's chain-of-thought setting so
our scores compare with the paper's.

## Planned changes

- `src/screamingface_engine_inspect/local_tasks/bbh/` (new): `bbh.py`, `README.md`.
- `prepare.py`, `benchmarks.py`: the importer's two rows, prose and provenance filled.
- Tests: `test_local_task_bbh.py` (new), `tests/unit/data/bbh_codex_cot_free_form_replies.json`
  (new), one row each in the shared per-Benchmark tables.

## Test plan

- The tag retype changes nothing else in a Sample; a non-enum tag is refused.
- Non-multiple-choice questions are sent as inspect_evals sends them; multiple choice carries the
  think-step-by-step instruction.
- Yes/no marking equals inspect_evals'; each wrong free-form shape inspect_evals passes is marked
  wrong.
- The free-form rule reproduces the authors' accuracy on their Codex replies (4 subsets).
- Real questions of every kind grade right and wrong through the aggregate route, no network.

## Acceptance

- 6,508 Cases sealed by Case Digest at `Joschka/big_bench_hard@76eaa8c2`, MIT, no judge.
- The four Codex accuracies reproduce exactly (56.8, 47.6, 93.2, 40.4).
