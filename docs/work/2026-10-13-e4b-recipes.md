# e4b-recipes — offline recipes for the combine scenarios that work on E4a

## Intent

Prove that the combine scenarios that already work on E4a (S1, S2, S5, S7, S8, S9, S10, S11 max)
run end to end, and give benchmark authors one recipe for each to copy. Each recipe is compiled by
the SDK into a url4 fixture, and the Engine runs it offline with a mocked gateway (ans:Q8). A
README section "Combine recipes" shows the same code. Spec:
`docs/spec/2026-10-13-e4b-combine-extensions/prd/recipes.md` (RC#1–13). Unit 2 of 7 of the plan
`docs/plan/2026-10-13-e4b-combine-extensions.md`. Stacks: screamingface-engine (tests and data),
screamingface (fixture builders, drift guard, README test, README).
