# e5-p1-runs-demo — Add a first-class Runs demo notebook

## Intent

Add a public, generated notebook that teaches researchers how to find, inspect, wait on, reopen,
and cancel Engine-owned Runs using the SDK's public API. The notebook must be safe to run by
default: paid evaluation and cancellation require explicit opt-in. The approved E5 P1 contract is
in `docs/spec/2026-10-27-e5-p1-first-class-run.md` and `docs/plan/2026-10-30-e5-p1-first-class-run.md`.

## Planned changes

- `packages/screamingface/scripts/build_notebooks.py` — author `20_runs.ipynb`.
- `packages/screamingface/examples/20_runs.ipynb` — deterministic generated output.
- `packages/screamingface/tests/test_runs_notebook.py` — verify the public Runs workflow and safe
  defaults.
- `packages/screamingface/scripts/check_notebooks.py` — include the Runs API in the public story.
- `packages/screamingface/README.md` — list the new notebook.

## Test plan

- Add a failing test that the generated notebook exposes the Runs workflow and that its evaluation
  and cancellation actions are disabled unless explicitly selected.
- Run that test, then the notebook determinism check and the `screamingface` quality gates.

## Acceptance

- The notebook can list/reopen Engine Runs and demonstrate progress, waiting, report recovery, and
  run-wide cancellation through the public SDK.
- Run All does not start paid evaluations or cancel an existing Run by default.
- The authored builder and checked-in notebook are deterministic and the README links the notebook.
