# e14-gw-replay — grant verification and version lookup on the chat path (OME-1307, E14b, wave 3)

## Intent

GW-capture and GW-freeze (merged) record and freeze a traced run. This unit lets the chat route
replay from a frozen version: a call that carries `X-AIGW-Cache-Replay` (an EdDSA grant minted by the
scoreboard) is verified (signature, expiry, audience, version exists, subject = caller), then looked
up in the version by the capture key. A version hit is served with no credential read and no provider
dispatch. A miss falls through to the normal path and is marked `X-AIGW-Cache-Version: miss`. An
invalid grant is `403 replay_grant_invalid` with a closed reason and never falls through.
Plan: `docs/plan/2026-09-29-e14-reproducible-submission/GW-replay.md`. Component: `apps/aigateway`
only. No migration.
