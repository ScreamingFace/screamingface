# e14-sdk-meta — edit submission metadata from the SDK (E14a, OME-1307)

## Intent

Add `update_submission` (sync and async, and a module facade) to the SDK. It sends
`PATCH /v1/scores/{id}` with `If-Match: "<n>"` and only the given fields (`authors`,
`paper_url`), decodes the new `LeaderboardScore.paper_url` and `metadata_revision`, maps the C5
error codes, retries one transport error, and uses a 15 s per-request timeout. `submit` gets an
optional `paper_url`. Plan: `docs/plan/2026-09-29-e14-reproducible-submission/SDK-meta.md`.
Spec: `docs/spec/2026-09-29-e14-reproducible-submission/` (MD-19, C5, C4 `paper_url`).
