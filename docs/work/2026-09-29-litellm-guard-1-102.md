# litellm-guard-1-102 — Re-verify the aigateway LiteLLM runtime guard against 1.102.0

## Intent

Dependabot #1025 moves aigateway's litellm 1.100.1 → 1.101.0 and trips the deliberate version
tripwire in `test_openai_runtime_guard.py`. Meanwhile #1066 moves the *distributed*
`packages/screamingface` pin to `litellm==1.102.0`. Re-verify the guard against 1.102.0 (not
1.101.0) so aigateway and the packaged runtime land on one verified version, following the
OME-1177 / #903 recipe. Unblocks #1025 and #1066 in the Dependabot sweep.

## Planned changes

- `apps/aigateway/uv.lock` — `uv lock --upgrade-package litellm` → 1.102.0 only
- `apps/aigateway/tests/unit/openai/test_openai_runtime_guard.py` — both tripwire pins → 1.102.0
- If 1.102.0 adds entries to `_supported_callback_params`: extend `_CALLBACK_DYNAMIC_FIELDS`
  + regression tests (as #903 did)

## Test plan

- RED: move the two version asserts to 1.102.0 while the lock is still 1.100.1 → both fail.
- GREEN: upgrade the lock → tripwires pass; existence sweeps prove every guarded global still
  exists; the dynamic-callback-param coverage test proves no new unstripped callback param.
- Full aigateway gates + live tests.

## Acceptance

- aigateway resolves litellm 1.102.0; full gates green; guard asserts 1.102.0.
