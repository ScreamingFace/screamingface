# e14-c1-docs — public docs and glossary for reproducible submissions

## Intent

E14 adds a paper link, owner edits and an edit log, a cache revision with a `reproducible` status for
each submission, and `sf.reproduce`. Users cannot find or trust the feature until the public docs
and the glossary describe it. This unit writes that text from the final SDK surface on this branch.
