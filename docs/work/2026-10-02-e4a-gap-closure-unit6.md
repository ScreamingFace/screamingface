## Notes

- F1: the warning is not added here. `5ae135c2a` already calls `_warn_duplicate_members` from
  `_reducer_synthesizer`, which `_fusion` reaches for any `Reducer`; unit 4 makes `sf.Reduce` a
  `Reducer`. `FixedSeedSittingWarning` reads only `candidate.parameter_assignments`. So BK#12,
  BK#14 and the U1 parity row pass at once. They are guard rows.
- F2: the engine half of BK#12 needs no engine change. The engine samples tests already run the
  block-form bytes (`FixtureVote` compiles to the same bytes as `sf.Vote` and `sf.Reduce`).
- F3: `sf.Url4(url4).to_python()` of a block-form samples Candidate prints `sf.Vote(...)`, not
  `sf.Reduce`, because the named class wins when its `_from_spec` accepts the spec (unit 5 F7).
- F4: the warning is emitted before `combine_spec_text`. An `sf.Reduce` op that does not compile
  yet warns first and then raises `ValueError`. Not pinned here.
- F5: BK#12 uses a local copy of the fixed-seed handler (seed row) with unit 5 `ScriptedTransport`.
- F6: both forms pin `last_number@2`; the tests assert the forms are equal, not a literal version.
- F7: `DuplicateMembersWarning` (direct Model members; route, prompt, params) and the unit 7
  `sources` rule I-C2 (path and params over the whole expression, prompts ignored) answer
  different questions. Do not merge them.
- F8: errata. BK-D7 cites `candidate.py:641`. The real call site is in `_reducer_synthesizer`
  (about `:443-460` after this rebase) and the function is `_warn_duplicate_members`.
