# E2E workbench · Unit 2 — core: notebooks driven by pytest, evidence by trace id (replay + local)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pytest tests/e2e/workbench` executes reviewable notebooks against a chosen target
(`replay` or `local`). It passes only when the notebook's own asserts hold *and* the run's trace
id shows up across engine and aigateway logs. Each run leaves an evidence bundle.

**Architecture:**
- **Location:** the workbench is a sub-lane of the existing replay suite at
  `packages/screamingface/tests/e2e/workbench/`, so it reuses `harness/` (replay stack, gating,
  assets) without copying it. The existing `screamingface-e2e-replay.yml` already runs
  `pytest tests/e2e`, so the replay target joins CI for free.
- **Notebooks** are generated by a deterministic builder and committed without outputs.
- **Runner:** nbclient executes them with a parameter cell injected after the cell tagged
  `parameters`.
- **Evidence:** a collector reads the target's log sources by trace id, and a bundle writer
  persists everything with secrets redacted.

**Tech Stack:** Python 3.12, pytest, nbclient ≥0.10, nbformat ≥5.11, ipykernel ≥6.29 (all
already SDK dev deps), the existing `tests/e2e/harness`.

**Spec:** `docs/spec/2026-10-16-e2e-notebook-workbench.md` §3, §3.2–3.4, §4.
**Depends on:** Unit 1 (`docs/plan/2026-10-16-e2e-workbench-u1-client-pairing-and-token.md`).
Notebooks pass both URLs explicitly, so they don't strictly depend on it, but the local target's
`sf.configure` use does.

## Global Constraints

- **No spend on replay:** the gateway is keyless and a cache miss is a failure (existing harness
  invariant).
- **Gating:**
  - **replay** goes through `harness._gating.require_e2e_stack()` (`SCREAMINGFACE_TEST_E2E=1` +
    docker).
  - **local** additionally requires `SCREAMINGFACE_TEST_PAID=1` and `OPENROUTER_API_KEY`.
- **Selection is by env var, not CLI option.** `pytest_addoption` in a non-initial conftest
  doesn't register when `pytest tests/e2e` is the invocation. The variables:
  - `SCREAMINGFACE_WORKBENCH_TARGET` = `replay` (default) | `local`
  - `SCREAMINGFACE_WORKBENCH_OUT` = bundle root (default `<tmp>/workbench-out`)
  - `SCREAMINGFACE_WORKBENCH_REQUIRE_ALL=1` turns any workbench skip into a failure
- **Notebooks under `tests/e2e/workbench/notebooks/` are output-free and byte-identical to the
  builder's output.** A test enforces this.
- **Secrets never land in a bundle.** Redact before writing:
  - `sk-[A-Za-z0-9_-]{16,}`
  - JWT-shaped `eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+`
  - `(?i)bearer\s+\S+`
- **Score assertions are bands** set by hand per scenario in the parameters cell (owner decision
  2026-10-16).
- **Gates:** `uv run pytest`, `uv run ruff check`, `uv run pyright` in `packages/screamingface`.
  Coverage floor is 95% (`screamingface-tests.yml`). Workbench code under `tests/` is not
  measured, but its unit tests run in the plain lane.

## Review Focus

1. **A failing notebook still leaves a bundle.** An `assert` failing in cell 5 must still write
   `executed.ipynb` (with the traceback) and `trace.json` with whatever was found. That is the
   evidence a reviewer opens. The runner returns the executed notebook *and* the error; it never
   just raises.
2. **An all-skipped run is not green.** With `SCREAMINGFACE_WORKBENCH_REQUIRE_ALL=1`, docker being
   absent fails the session.
3. **No trace id.** If a run errors before any frame, the result cell may never run. The test must
   fail with "no trace id reported", not pass vacuously on an empty chain.
4. **The kernel interpreter.** nbclient must execute with the SDK venv's interpreter, not a
   user-level `python3` kernelspec pointing elsewhere. Use a private kernelspec dir.
5. **Secrets in outputs.** A notebook that prints an env key into an output cell must have it
   redacted in the saved `executed.ipynb`.

# tests/e2e/workbench/runner.py
"""Execute one workbench notebook with injected parameters (e2e workbench spec §3.2).

INVARIANT: a failed cell never loses the evidence — the executed notebook (with the traceback
in its outputs) is returned together with the error text, and the caller writes both.
"""

from __future__ import annotations

import json
import os
import sys
import tempfile
from collections.abc import Iterator, Mapping
from contextlib import contextmanager
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import nbformat
from nbclient import NotebookClient
from nbclient.exceptions import CellExecutionError

RESULT_PREFIX = "WORKBENCH_RESULT="
_KERNEL = "sf-workbench"
_LITERALS = (str, int, float, bool, type(None), list, dict)


@dataclass(frozen=True)
class NotebookRun:
    executed: nbformat.NotebookNode
    result: dict[str, Any] | None
    error: str | None


def _literal(name: str, value: Any) -> str:
    if not isinstance(value, _LITERALS):
        raise TypeError(f"parameter {name} must be a JSON-like literal, got {type(value)!r}")
    return f"{name} = {value!r}"


def _inject(nb: nbformat.NotebookNode, params: Mapping[str, Any]) -> None:
    index = next(
        (i for i, c in enumerate(nb.cells) if "parameters" in c.metadata.get("tags", [])), None
    )
    if index is None:
        raise ValueError("notebook has no cell tagged 'parameters'")
    cell = nbformat.v4.new_code_cell("\n".join(_literal(k, v) for k, v in params.items()))
    cell.metadata["tags"] = ["injected-parameters"]
    nb.cells.insert(index + 1, cell)


@contextmanager
def _private_kernelspec() -> Iterator[None]:
    """WHY: a user-level `python3` kernelspec may point at another interpreter; the workbench
    must execute with THIS venv's SDK."""
    with tempfile.TemporaryDirectory() as root:
        spec_dir = Path(root) / "kernels" / _KERNEL
        spec_dir.mkdir(parents=True)
        (spec_dir / "kernel.json").write_text(
            json.dumps(
                {
                    "argv": [sys.executable, "-m", "ipykernel_launcher", "-f", "{connection_file}"],
                    "display_name": _KERNEL,
                    "language": "python",
                }
            )
        )
        previous = os.environ.get("JUPYTER_PATH")
        os.environ["JUPYTER_PATH"] = root + (os.pathsep + previous if previous else "")
        try:
            yield
        finally:
            if previous is None:
                os.environ.pop("JUPYTER_PATH", None)
            else:
                os.environ["JUPYTER_PATH"] = previous


def _result(nb: nbformat.NotebookNode) -> dict[str, Any] | None:
    for cell in nb.cells:
        if "workbench-result" not in cell.metadata.get("tags", []):
            continue
        for output in cell.get("outputs", []):
            for line in str(output.get("text", "")).splitlines():
                if line.startswith(RESULT_PREFIX):
                    return json.loads(line[len(RESULT_PREFIX) :])
    return None


def run_notebook(path: Path, params: Mapping[str, Any], *, timeout_s: int = 900) -> NotebookRun:
    nb = nbformat.read(path, as_version=4)
    _inject(nb, params)
    error: str | None = None
    with _private_kernelspec():
        client = NotebookClient(
            nb, kernel_name=_KERNEL, timeout=timeout_s, resources={"metadata": {"path": str(path.parent)}}
        )
        try:
            client.execute()
        except CellExecutionError as exc:
            error = str(exc)
    return NotebookRun(executed=nb, result=_result(nb), error=error)
```

# tests/e2e/harness/trace_evidence.py
"""Trace-evidence checks shared by the correlation ladder and the workbench (OME-938, OME-1105).

One implementation, two log sources: files on disk here, pod logs in the cloud targets.
"""

from __future__ import annotations

import re

TRACE_ID = re.compile(r"\b[0-9a-f]{32}\b")
CALL_ID_MARK = "gateway_call_id="


def unattributed_gateway_lines(text: str) -> tuple[int, list[str]]:
    """(identified-line count, lines in the request window that carry no call id).

    The window runs from the first to the last identified line: startup/shutdown lines belong
    to no request and are outside it (see rung 3's docstring for why).
    """

    lines = [ln for ln in text.splitlines() if ln.strip()]
    identified = [i for i, ln in enumerate(lines) if CALL_ID_MARK in ln]
    if not identified:
        return 0, []
    window = lines[identified[0] : identified[-1] + 1]
    return len(identified), [ln for ln in window if CALL_ID_MARK not in ln]
```

# tests/e2e/workbench/evidence.py
"""Collect a run's trace chain from a target's log sources (e2e workbench spec §3.3)."""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, Protocol

from harness.trace_evidence import unattributed_gateway_lines

_MAX_LINES = 500


class LogSource(Protocol):
    name: str

    def read(self) -> str: ...


@dataclass(frozen=True)
class FileLogSource:
    name: str
    path: Path

    def read(self) -> str:
        return self.path.read_text(errors="replace") if self.path.is_file() else ""


@dataclass(frozen=True)
class Hop:
    name: str
    found: bool
    lines: tuple[str, ...]


@dataclass(frozen=True)
class TraceChain:
    trace_ids: tuple[str, ...]
    hops: tuple[Hop, ...]
    lifecycle: dict[str, bool] = field(default_factory=dict)
    unattributed: list[str] = field(default_factory=list)

    def missing(self, required: Sequence[str]) -> list[str]:
        found = {h.name for h in self.hops if h.found}
        return [name for name in required if name not in found]

    def to_json(self) -> dict[str, Any]:
        return {
            "trace_ids": list(self.trace_ids),
            "hops": [{"name": h.name, "found": h.found, "lines": len(h.lines)} for h in self.hops],
            "lifecycle": self.lifecycle,
            "unattributed_gateway_lines": len(self.unattributed),
        }


def _matching(text: str, trace_ids: Sequence[str]) -> tuple[str, ...]:
    if not trace_ids:
        return ()
    hits = [ln for ln in text.splitlines() if any(t in ln for t in trace_ids)]
    return tuple(hits[:_MAX_LINES])


def collect(trace_ids: Sequence[str], sources: Sequence[LogSource]) -> TraceChain:
    hops: list[Hop] = []
    lifecycle = {"scheduled": False, "terminated": False}
    unattributed: list[str] = []
    for source in sources:
        text = source.read()
        lines = _matching(text, trace_ids)
        hops.append(Hop(source.name, bool(lines), lines))
        lifecycle["scheduled"] |= any(ln.startswith("run scheduled") or " run scheduled " in ln for ln in lines)
        lifecycle["terminated"] |= any(ln.startswith("run terminated") or " run terminated " in ln for ln in lines)
        if source.name == "aigateway":
            unattributed += unattributed_gateway_lines(text)[1]
    return TraceChain(tuple(trace_ids), tuple(hops), lifecycle, unattributed)
```

The `run scheduled` / `run terminated` prefixes are the stable strings in
`apps/screamingface-engine/src/screamingface_engine/run_evidence.py` (`SCHEDULED`, `TERMINATED`).
Log formatters may prepend timestamp and level, which is why the code checks for a substring as
well as the line start.

# tests/e2e/workbench/bundle.py
"""Write one notebook run's evidence bundle (e2e workbench spec §3.3). Secrets never land."""

from __future__ import annotations

import json
import re
from collections.abc import Sequence
from pathlib import Path

import nbformat

from workbench.evidence import TraceChain
from workbench.runner import NotebookRun

_SECRETS = (
    re.compile(r"sk-[A-Za-z0-9_-]{16,}"),
    re.compile(r"eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+"),
    re.compile(r"(?i)bearer\s+\S+"),
)


def redact(text: str) -> str:
    for pattern in _SECRETS:
        text = pattern.sub("[REDACTED]", text)
    return text


def write_bundle(
    root: Path,
    *,
    target: str,
    notebook: str,
    run: NotebookRun,
    chain: TraceChain,
    passed: bool,
    reasons: Sequence[str],
) -> Path:
    out = root / target / notebook
    (out / "logs").mkdir(parents=True, exist_ok=True)
    (out / "executed.ipynb").write_text(redact(nbformat.writes(run.executed)))
    for hop in chain.hops:
        (out / "logs" / f"{hop.name}.txt").write_text(redact("\n".join(hop.lines)))
    trace = chain.to_json() | {
        "passed": passed,
        "reasons": list(reasons),
        "result": run.result,
        "error": redact(run.error) if run.error else None,
    }
    (out / "trace.json").write_text(json.dumps(trace, indent=2))
    summary = root / "summary.md"
    if not summary.exists():
        summary.write_text("| target | notebook | outcome | trace ids | reasons |\n|---|---|---|---|---|\n")
    with summary.open("a") as fh:
        ids = ", ".join(chain.trace_ids) or "—"
        fh.write(f"| {target} | {notebook} | {'PASS' if passed else 'FAIL'} | {ids} | {'; '.join(reasons) or '—'} |\n")
    return out
```

# tests/e2e/workbench/test_notebooks.py
"""Each workbench notebook × the selected target. Passes only if the notebook AND the trace
chain agree (e2e workbench spec §2 D3)."""

from __future__ import annotations

from pathlib import Path

import nbformat
import pytest

from workbench.build_notebooks import NOTEBOOK_DIR
from workbench.bundle import write_bundle
from workbench.evidence import collect
from workbench.runner import run_notebook
from workbench.targets import selected_target

NOTEBOOKS = sorted(NOTEBOOK_DIR.glob("*.ipynb"))


def _supports(path: Path, target: str) -> bool:
    meta = nbformat.read(path, as_version=4).metadata.get("workbench", {})
    return target in meta.get("targets", [])


@pytest.mark.e2e
@pytest.mark.parametrize("path", NOTEBOOKS, ids=lambda p: p.stem)
def test_notebook(path: Path, live_target, workbench_out: Path) -> None:
    if not _supports(path, live_target.name):
        pytest.skip(f"{path.stem} does not declare target {live_target.name}")
    params = {"ENGINE_URL": live_target.engine_url, "SCOREBOARD_URL": live_target.scoreboard_url}
    run = run_notebook(path, params | live_target.params)

    trace_ids = list((run.result or {}).get("trace_ids", []))
    chain = collect(trace_ids, live_target.sources)
    reasons: list[str] = []
    if run.error:
        reasons.append("notebook failed: " + run.error.splitlines()[-1])
    if not trace_ids:
        reasons.append("no trace id reported by the notebook")
    if missing := chain.missing(live_target.required_hops):
        reasons.append(f"trace {trace_ids} not found in: {', '.join(missing)}")
    if chain.unattributed:
        reasons.append(f"{len(chain.unattributed)} aigateway lines lack gateway_call_id")

    bundle = write_bundle(
        workbench_out,
        target=live_target.name,
        notebook=path.stem,
        run=run,
        chain=chain,
        passed=not reasons,
        reasons=reasons,
    )
    assert not reasons, f"{'; '.join(reasons)} — evidence: {bundle}"
