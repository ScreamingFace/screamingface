# LAB-Bench FigQA — Fidelity Record

## Verdict

**`comparable-to-inspect`.** Our FigQA headline is plain accuracy over the 181 public Cases. It can sit beside an accuracy from [inspect_evals' `lab_bench_figqa` (v0.20.0, eval version 2-A)](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/lab_bench). It cannot sit beside the [LAB-Bench paper's](https://arxiv.org/abs/2407.10362v3) FigQA bars, and this record does not vouch for the row's frontier score (see Upstream notes).

Ours matches inspect_evals on every dimension that can change a mark:
- **Prompt and picture:** all 181 Cases rendered both ways. The text part equals the user text inspect_evals' own solver renders, byte for byte. The picture bytes equal inspect's picture bytes and the Hub figure bytes on every Case. Neither side sends a system message.
- **Marks:** 181 Cases × 18 pre-written replies, plus the empty answer as the runtime passes it, gives 3,439 marks. All equal inspect_evals' own `precision_choice` marks.
- **Headline:** our mean equals inspect's `accuracy()` to four decimals on 6 fixed mark vectors.

The one difference against inspect_evals is cosmetic (D1): we do not publish its secondary `precision`, `coverage` and `stderr` metrics. Arithmetic: `sum of bounds against inspect_evals = 0/181 = 0.0000 ≤ COMPARABLE_TOLERANCE (0.005)`.

Against the [authors' harness](https://github.com/Future-House/LAB-Bench/tree/a767892307ad38a5f4f77cd00d30c2442aaea791), inspect_evals differs beyond tolerance:
- **Prompt:** a different template that asks for a different answer format. The picture comes before the text instead of after it.
- **Answer extraction:** a different extractor. On every Case, a correct reply in either side's own format is marked wrong by the other side.
- **Dataset:** the paper's numbers cover the full 226-question set (public plus private), averaged over three runs. We and inspect_evals run the 181 public questions.

The prompt and extraction bound is `unbounded` because it depends on the model. So the rule gives `comparable-to-inspect`, not `comparable-to-paper`.
