# ChemBench — Fidelity Record

## Verdict

**`unverified`.** Our headline is plain accuracy over the 2,785 ChemBench questions at Hub revision [`a8f7e226`](https://huggingface.co/datasets/jablonkagroup/ChemBench/tree/a8f7e226e0d01553018194711b4b3d87d5a5164e). The audit could not settle whether it can sit beside a run of [inspect_evals v0.20.0 `chembench`](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/chembench), and it cannot sit beside the paper's or [the ChemBench leaderboard's](https://huggingface.co/datasets/jablonkagroup/ChemBench-Results) numbers either. This is by design. The row's own Named Deviation (D2) swaps inspect_evals' string compare of the answer letters for the set compare from [inspect_evals PR #2591](https://github.com/UKGovernmentBEIS/inspect_evals/pull/2591). That moves us toward the ChemBench authors' rule and away from the pinned inspect_evals.

Against inspect_evals, everything except D2 matches:

- **Cases:** Case Preparation reproduces the sealed digests.
- **Prompts:** all 2,785 Candidate inputs equal inspect's own prompt builders byte for byte.
- **Numeric marks:** identical on every numeric sheet.
- **Roll-up:** equal to four decimals on seven vectors.

D2, though, can change the mark on any of the 2,542 multiple-choice Cases: on 394 of them for a reordered or space-separated right answer, and on every one for a repeated letter. How many Cases move on a real run depends on how the Candidate writes its letters, and no recorded replies exist to rescore, so D2 is `possibly-score-changing` with bound `unknown` (worst case 2542/2785 = 0.9127). `sum of stated bounds against inspect_evals = 0 (D1) + 0 (D3) = 0`, plus D2 open → `unverified`. D2 would be bounded within tolerance if, on a real run, ours and v0.20.0 differ on at most 13 Cases (`13/2785 = 0.0047 ≤ COMPARABLE_TOLERANCE (0.005)`).

Against the original harness ([lamalab-org/chembench@45f8bad0](https://github.com/lamalab-org/chembench/tree/45f8bad062fe552810c52be3a328d5da8597ed30)), our multiple-choice marks equal the harness's on every sheet it decides without its LLM extractor, with one exception. A reply with two `[ANSWER]` blocks differs on 2,522 Cases, because the harness joins every block. The prompt header and option labels also differ on every Case, and the numeric rule differs on 12 Cases plus unit-bearing replies. `bounds vs original harness ≥ 2522/2785 = 0.9056 > 0.005`. The harness comparison is past tolerance on its own; against inspect_evals the open question is D2's real-run size.

## Deviations

### D1 — row order forced by a seed

- **Not in a declared form, documented.** The row sets `shuffle_seed=20260917` (`apps/screamingface-engine/src/screamingface_engine_inspect/prepare.py:1679`). The mechanism is the D1 row of `docs/spec/2026-10-02-ome-1460-one-fetch-path.md:281`, and the Benchmark description says "Cases are served in a fixed seeded shuffle (the eval shuffles per run)" (`benchmarks.py:6090-6091`). No `# NAMED DEVIATION` line names it, so by the strict list this is undeclared. It is cosmetic, so it moves no bound.
- **Where.** Ours: `fetch_pins_of(spec)` (`apps/screamingface-engine/src/screamingface_engine_inspect/task_replay.py:404-411`) forces the seed onto the eval's `hf_dataset(shuffle=True)`. Theirs: `inspect_evals:chembench/chembench.py:145-152` (`shuffle=shuffle`, default `True` at `:169`, no seed) → `inspect_ai:dataset/_sources/hf.py:264-265`.
- **What differs.** The order within each of the nine subset blocks. Ours is one fixed permutation; inspect's is a fresh one per run. Every Case's text, options, key and metadata are identical (dataset row).
- **Severity / bound.** `cosmetic`, `0`. A mark does not depend on position: the same marks come out of every sheet in our order.

### D2 — multiple choice marked by the set of letters (inspect_evals PR #2591)

- **Declared.** `# NAMED DEVIATION` at `apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:6103-6107`. The row's scorer is `screamingface_engine_inspect.named_deviations.chembench.chembench:chembench_scorer` (`:6108`), a module under `named_deviations/`. The description says so too (`benchmarks.py:6087-6090`).
- **Where.** Ours: `apps/screamingface-engine/src/screamingface_engine_inspect/named_deviations/chembench/chembench.py:60-85`, `answer_letters = set(re.findall(r"[A-Z]", answer.upper()))` against `set(target.text.upper().split(","))` (`:77-78`). Theirs: `inspect_evals:chembench/chembench.py:224`, `pattern(pattern=MCQ_REGEX_TEMPLATE)`, whose `match_target` tests `match.lower() in [target.lower()]`, a whole-string compare (`inspect_ai:scorer/_pattern.py:12-17`).
- **What differs.** A right answer written in any form other than the key's own string. On the 394 multi-letter Cases, `A, D`, `A D` and `D,A` against key `A,D` are 1 for ours and 0 for inspect. On any of the 2,542 multiple-choice Cases, a repeated letter (`B,B` against `B`) is 1 for ours and 0 for inspect. Every other sheet marks alike: a missing or extra letter, the wrong letter, no tags, empty, lowercase, `<ANS>`, a trailing period, and multiple tags (first match wins on both sides).
- **Severity / bound.** `possibly-score-changing`, `unknown`; worst case `2542/2785 = 0.9127`, the Cases on which some reply gets a different mark, which is every multiple-choice Case. The narrower set, where a natural reply format the prompt invites ("comma- or space-separated list") flips the mark, is the 394 multi-letter Cases: 394/2785 = 0.1415, also above tolerance. They are the Cases whose key contains a comma, first ids `44, 115, 120, 1249, 1261, …`, last `2783, 2784, 2785`. Their ids are in `multi_case_ids.json` of the audit scratch (rebuildable with Checks run 4). How much this moves a real run depends on how often a Candidate writes the letters in another form. No recorded ChemBench replies exist in `tests/unit/inspect/goldens/` or `tests/fixtures/`, so that rate is not measured here (Recommended paid runs).
- **Evidence.** Checks run 6 and 7. The deviation brings ours in line with the original harness on these sheets: its `all_correct` is `hamming == 0` over sets (`fork:src/chembench/prompter.py:295`, `fork:src/chembench/metrics.py:92-111`). Ours == harness on `gold_comma_space`, `gold_reversed` and `gold_with_first_letter_repeated` on all 2,542 (Checks run 9).

### D3 — only the pooled headline of the grouped metric is published

- **Declared.** `# NAMED DEVIATION` at `apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:6114-6116`; description `:6091-6092` ("the eval's per-topic breakdown is not reproduced").
- **Where.** Ours: `apps/screamingface-engine/src/screamingface_engine_inspect/single_shot.py:1275-1303`. Theirs: `grouped(accuracy(), "subset_name")` (`inspect_evals:chembench/chembench.py:222`), whose `all` is the pooled sample mean (`inspect_ai:scorer/_metrics/grouped.py:19`, `:85-87`), plus `stderr()`.
- **What differs.** We publish `all` alone. The nine per-subset accuracies and the stderr are not published.
- **Severity / bound.** `cosmetic`, `0`. The headline equals inspect's `all` to four decimals on seven vectors (Checks run 8). Note: inspect's `all="groups"` reading would differ (0.8179 vs 0.9127 on the sheet vectors), but the eval does not use it.

## Recommended paid runs

One run would bound D2. Run ChemBench once on any Candidate through the Engine, then re-mark the recorded replies of every multiple-choice Case through both v0.20.0 `chembench_scorer` and ours. ## Upstream notes

- **inspect_evals vs the original harness: a different examiner, past tolerance.** [inspect_evals v0.20.0 `chembench`](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/chembench) departs from [lamalab-org/chembench@45f8bad0](https://github.com/lamalab-org/chembench/tree/45f8bad062fe552810c52be3a328d5da8597ed30) in six ways:
  1. **Prompt.** The harness's `InstructionPrompter` opens with "The following is a multiple choice question about chemistry." (`fork:src/chembench/constant.py:84`) or "The following is a question about chemistry." (`:109`). inspect's templates open with "… that you must answer as truthfully as possible." (`inspect_evals:chembench/chembench.py:38`, `:62`). The harness labels options `A. text` (`fork:src/chembench/prompter.py:1093`), inspect `A) text` (`inspect_ai:solver/_multiple_choice.py:67`). With those two rewrites, all 2,785 prompts are byte-equal (Checks run 9), down to the LaTeX/SMILES stripping. Its effect on a Candidate is unmeasured: `unknown`.
  2. **Letter regex.** The harness's `MCQ_REGEX_TEMPLATE_1` allows commas only (`[A-Z](?:,\s*[A-Z])*`, `fork:src/chembench/constant.py:147`) and is case-sensitive. inspect's allows `[,\s]` (`inspect_evals:chembench/chembench.py:60`) under `IGNORECASE`. Space-separated letters (394 Cases) and lowercase letters (2,542) fail the harness's regex and go to its LLM extractor.
  3. **Several `[ANSWER]` blocks.** The harness takes `sorted(set(re.findall(...)))` over the whole reply and unions the letters of every block (`fork:src/chembench/prompter.py:878`, `:380`). inspect takes the first block. A reply that gives the right block and then a wrong one is 1 under inspect and 0 under the harness on 2,522 Cases (2522/2785 = 0.9056).
  4. **LLM extraction fallback.** When the regex fails, the harness asks an LLM to read the reply (`fork:src/chembench/prompter.py:887`, and the numeric path in `prepare_general_answer` `:912`). Its `LLMExtractor` is built from **the model under test** (`fork:src/chembench/prompter.py:164`). inspect marks such a reply 0. On the sheets, 8,506 of 40,560 marks went to this fallback. Its marks are `unknown` without that model.
  5. **Refusal detection and re-ask.** The harness runs `hybrid` refusal detection by default (`fork:src/chembench/prompter.py:171`): keywords plus the [ProtectAI/distilroberta-base-rejection-v1](https://huggingface.co/ProtectAI/distilroberta-base-rejection-v1) classifier (`fork:src/chembench/refusal.py:45-46`). On a refusal it asks the Candidate again (`fork:src/chembench/prompter.py:354-362`, one retry by default). inspect does neither.
  6. **Numeric rule.** The harness credits `mae < 0.01 * float(target)` (`fork:src/chembench/prompter.py:297-300`), because the Hub has no `relative_tolerance` column (`fork:src/chembench/task.py:260`, Checks run 5). That threshold is strict and signed, so it never credits the 9 negative-target and 3 zero-target Cases (12/2785 = 0.0043). inspect uses `<= abs(target * 0.01)` with `atol 1e-8` at zero (`inspect_evals:chembench/mae_scorer.py:34-39`). On the sheets they also split at exactly +1% on 4 positive Cases (`1200, 1877, 2027, 2037`). And for a number with units inside the tags (`[ANSWER]10 g/mol[/ANSWER]`) the harness's `find_numbers` credits it while inspect's `float()` fails (231 Cases).

  The multiple-choice metric itself agrees with the harness only after our D2: the harness compares sets (`fork:src/chembench/metrics.py:40`, `hamming == 0` at `fork:src/chembench/prompter.py:295`). Taken together the gap is past tolerance, so inspect_evals is not comparable to the paper either.
