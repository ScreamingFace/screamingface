## Verdict

**`not-comparable`.** Our Candidate reads the same 379 prompts as [inspect_evals' `coconot(subset="contrast")`](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/coconot), byte for byte. Those are the same 379 ids, prompts and subcategories as the [authors' harness](https://github.com/allenai/noncompliance/tree/25bf77cc668814360405cdb8197c4368205806c7) file (Checks run 5). Our grading hook builds the same judge prompt and gives the same mark as inspect's own `model_graded_qa` and reducer on 13,644 answer sheets (Checks run 7). Our headline equals inspect's `total / 100` to four decimals on 7 vectors (Checks run 8). But the examiner is not the paper's. The [paper](https://arxiv.org/abs/2407.12043v2) and the harness grade with GPT-3.5-turbo, the harness's own judge prompt, a system turn and the harness's first-`<label>` parser (§3.3 and footnote 6; `fork:eval/response_evaluation_refusal.py:31-38,53,64-65,86-120`). They report the contrast number "averaged across sub-categories" (Table 3 caption). Our row grades with the house judge `openrouter/openai/gpt-5.4` (`apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:306-315`, declared). Spec §2.3 makes a judge model other than the paper's `not-comparable` by rule. ## Deviations

### D1: one pooled mean instead of inspect's per-category compliance rates ×100

- **Declared.** `# NAMED DEVIATION` on the row, `apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:3438-3440` (example 340/379 → inspect 89.7, ours 0.897).
- **Where.** Ours: `apps/screamingface-engine/src/screamingface_engine_inspect/single_shot.py:1303`. Theirs: `inspect_evals:coconot/coconot.py:221-240`. Their `total` key pools every scored sample (`:230`), and the per-category keys group on `category` (`:227`).
- **What differs.** The scale (×100) and the per-category columns. The headline value does not differ: ours equals `total/100` on all 7 vectors, including the two with unscored samples (Checks run 8).
- **Severity / bound.** `cosmetic`, `0`.

### D2: the house judge replaces inspect's default grader

- **Declared.** `# NAMED DEVIATION` on `_COCONOT_JUDGE`, `apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:307-310` ("its scores are NOT directly comparable to an inspect run with the default judge"). The row binds it at `:3455`.
- **Where.** Ours: `benchmarks.py:303,311,314`. Theirs: `inspect_evals:coconot/coconot.py:138`.
- **What differs.** The judge model (`openai/gpt-5.4` vs `openai/gpt-3.5-turbo`) and its params (ours caps at 4096 tokens and turns web search off; inspect's grader runs on provider defaults). The prompt bytes and parsing are identical (Checks run 7).
- **Severity / bound.** `possibly-score-changing`, `unknown`. Only a paired judge run bounds it (Recommended paid runs). Against the paper this is a different examiner by design: spec §2.3 rules `not-comparable`.

### D3: the Candidate runs without inspect's temperature 0 and 256-token cap

- **Undeclared (finding).** The row's description says it in prose (`benchmarks.py:3424-3426`), and `tests/unit/inspect/test_verdict_grades.py:364` pins inspect's values. But it has no `# NAMED DEVIATION` line, no `named_deviations/` scorer and no linked README paragraph.
- **Where.** Theirs: `inspect_evals:coconot/coconot.py:184`. Ours: no `params` on the row (Checks run 2).
- **What differs.** inspect's Candidate decodes greedily and stops at 256 tokens. Ours uses provider defaults with no cap. The judge reads the whole reply, so a reply that complies first and hedges after token 256 can get a different label.
- **Severity / bound.** `possibly-score-changing`, `unknown`. 379 Cases; a paired Candidate run bounds it.
