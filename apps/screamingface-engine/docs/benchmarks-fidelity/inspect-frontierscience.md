# FrontierScience — Fidelity Record

## Verdict

**`not-comparable`.** Our headline (mean judge grade over the 160 Cases, Olympiad and Research pooled) cannot sit beside the [paper's](https://arxiv.org/abs/2601.21165v1) two published numbers (GPT-5.2: 77.1% Olympiad, 25.2% Research, Fig. 6) because the examiner is a different model by design: the row pins `openrouter/openai/gpt-5.4` through our gateway with only `web_search=false` and `max_tokens=4096` (`benchmarks.py:1813-1825`), where the paper grades with "GPT-5 at high reasoning effort" (§2.3, Appendix B). The row declares this as a `NAMED DEVIATION` (`benchmarks.py:1815-1820`) and the catalogue prose says the scores "are NOT comparable to the paper's published numbers". Every deterministic dimension matches [inspect_evals](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/frontierscience) exactly: the 160 Cases are the pinned Hub rows byte for byte, the Candidate prompt is the problem text untouched, the judge prompt bytes are identical on 3,360 answer sheets, every mark is identical, and the roll-up agrees to four decimals on four vectors. Bound arithmetic: `D2 (judge) is unbounded by design → not-comparable`; `sum of bounds against inspect_evals on the deterministic dimensions = 0/160 = 0.0000`; `D3 (failed-Case roll-up) = unknown` and `D4 (Candidate sampling) = unbounded` would each on their own block `comparable-to-paper` as well. The verdict would not become `comparable-to-inspect` even with the judge settled: inspect_evals itself departs from the paper on the Research metric (continuous points/10 vs the paper's ≥7-point pass threshold, Upstream notes) and on the Olympiad judge prompt's verdict line.

## Deviations

### D1 — Case order is a seeded shuffle, inspect's is unseeded

- **Declared** on the replay spec's fold comment: "order forced by shuffle_seed through inspect's shuffle (D1)" (`apps/screamingface-engine/src/screamingface_engine_inspect/prepare.py:1044,1058`).
- **Where.** Ours: `prepare.py:1058` (`shuffle_seed=20260923`). Theirs: `inspect_evals:frontierscience/frontierscience.py:356,385` (`shuffle: bool = True`, `shuffle=shuffle` with no seed).
- **What differs.** The same 160 Samples in a fixed order (Case ids 1..160 positional) instead of a fresh random order per `eval()`: `order: ours == ref order? False`, `multiset equal: True` (Checks run 10).
- **Severity / bound.** `cosmetic`, `0`: each Case is graded alone; order cannot change a mark.

### D2 — the judge is not the paper's

- **Declared.** `# NAMED DEVIATION` on the row (`apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:1815-1820`): "the original FrontierScience paper uses GPT-5 at HIGH reasoning effort as the model judge … This benchmark pins the house judge … so its scores are NOT comparable to the paper's published numbers." Also `docs/adding-an-imported-benchmark.md:250-251` names it as the precedent.
- **Where.** Ours: `benchmarks.py:1813` (`scorer_kwargs={"model": "screamingface/openrouter/openai/gpt-5.4"}`), `:1821-1825` (model and params); the transport's allowlist `judge_provider.py:332-343` sends only those params. Theirs: paper §2.3 (p.5) "We use GPT-5 at high reasoning effort for the model judge"; Appendix B (p.12) "a judge model based on GPT-5 thinking at high reasoning effort".
- **What differs.** Model (gpt-5.4 vs GPT-5), reasoning effort (unpinned vs high), route (our gateway). Prompt bytes and reply parsing are inspect_evals' and identical on both sides (Checks run 13); inspect_evals' olympic prompt itself differs from the paper's (Upstream notes).
- **Severity / bound.** `score-changing`, `unbounded`: a different grader by design; the spec's rule for "a judge model other than the one the paper's number used" is `not-comparable`.

### D3 — a Case the judge gives no verdict on counts 0 in our mean, is dropped from inspect's

- **Undeclared.** `failure_policy="withhold"` is on the row (`benchmarks.py:1805`) and documented in `_accuracy` (`single_shot.py:1276-1282`, OME-1642), but no `NAMED DEVIATION` line or README names the difference from inspect's aggregation.
- **Where.** Ours: `scorer_adapter.py:301-313` (`_outcome` fails the Case `invalid_score_value` on an unmappable Score; NaN is unmappable, `:873-878`), then `single_shot.py:1303` (`sum(values) / len(cases)` over every selected Case). Theirs: `inspect_ai:scorer/_model.py:349` (`Score.unscored`), `inspect_ai:_eval/task/results.py:404-414` (NaN Samples excluded before `mean()`, counted as `unscored_samples`).
- **What differs.** Olympic only (the research scorer returns `0.0`, never unscored, `frontierscience.py:229-235`): a judge reply with no `GRADE: C|I` (300 of the 2,100 olympic sheet triples by construction, Checks run 13) lowers our headline and leaves inspect's untouched. A blank judge reply is `JudgeReplyBlank` on ours (`judge_provider.py:311`), unscored on inspect's — same shape.
- **Severity / bound.** `possibly-score-changing`, `unknown`: the count of such Cases is the judge's behaviour on live replies. Recommended run below.

### D4 — Candidate reasoning effort, browsing and trials are not pinned

- **Undeclared.** The row carries no sampling pins; nothing names the paper's settings.
- **Where.** Ours: the row (`benchmarks.py:1786-1860`) and `declaration … attempts=1` (Checks run 2). Theirs: paper §3.1 (p.5-6) "All reasoning models were evaluated at 'high' reasoning effort with the exception of GPT-5.2 at 'xhigh', and without browsing"; Fig. 6 caption (p.7) "averaged across 20 independent trials … 30 independent trials".
- **What differs.** Effort and browsing are left to the Candidate's Model Config; one attempt instead of 20/30 trials (same expectation, more variance).
- **Severity / bound.** `score-changing`, `unbounded` for effort/browsing (what the Candidate produces); the trial count alone would be `cosmetic` in expectation.
