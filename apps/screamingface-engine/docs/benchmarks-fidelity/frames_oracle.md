# FRAMES (articles given) — Fidelity Record

## Verdict

**`not-comparable`.** The published number our headline would sit beside is the paper's Oracle Prompt accuracy, 0.729 for Gemini-Pro-1.5-0514 ([Table 3](https://arxiv.org/abs/2409.12941v1); `arxiv-src:v1/results/table/single_step.tex:12`, unchanged in v3 at `:50`). That number came from a different examiner by design: the paper's rater was Gemini-Pro-1.5-0514 (`arxiv-src:v1/040experiments.tex:13`, macro at `iclr2025_conference.tex:169`), ours is `openrouter/openai/gpt-5.4` (`apps/screamingface-engine/src/screamingface_engine_inspect/benchmarks.py:5040`, a declared Named Deviation at `:5037-5039`). Spec §2.3 names exactly this case ("a judge model other than the one the paper's number used") as `not-comparable`, so the verdict does not depend on the bound arithmetic. For the record: the one enumerable deviation is the two excluded questions, `2/824 = 0.0024 ≤ 0.005`; the other three (article text from our 2024-09-19 snapshot, our own Candidate prompt, the judge model) are `unbounded` because the paper publishes neither its article text nor its oracle template, and its judge cannot be rerun by us. What does match, with evidence: the rater prompt and system message are the paper's Figure 6 byte for byte (v1 and v3 LaTeX transcribed and compared), the whole reply goes to the rater on both sides, TRUE/FALSE maps to 1/0, and the roll-up is `correct / total` to four decimals on four fixed mark vectors.

## Deviations

### D1 — two questions left out (official rows 77 and 141)

- **Declared.** `# NAMED DEVIATION (OME-1481 decisions 9 and 10)` on the row, `apps/screamingface-engine/src/screamingface_engine_inspect/prepare.py:1488-1495`; README `local_tasks/frames/README.md:28-32`; row description `benchmarks.py:5017-5018`; pinned by `test_the_row_pins_the_house_judge_and_drops_the_two_unanswerable_questions` (`test_local_task_frames.py:412-427`).
- **Where.** Ours: `excluded_sample_ids=("77","141")`, `spec.case_count 822`. Theirs: 824 questions (`arxiv-src:v1/iclr2025_conference.tex:171`; card `hub:google/frames-benchmark@58d9fb63/README.md:32`).
- **What differs.** Row 141's only gold article was deleted from Wikipedia on 2024-07-01, row 77's answer needs a table a since-deleted template drew (snapshot card `:123-125`). The paper scored both.
- **Severity / bound.** `score-changing`, `2/824 = 0.0024` — Cases are the two official rows, enumerated by the row and by `kept 822 excluded ['141','77']` (Checks run 7).

### D2 — article text from our 2024-09-19 snapshot, not the text the annotators read

- **Declared.** README `:22-26` and the row description `benchmarks.py:5019-5022` ("frozen at their last revision before 2024-09-19, but Wikipedia draws an old revision with today's templates…"); the snapshot card's Known limitations (`hub:khoaguin/frames-wikipedia-2024-09-19@6ada7fb7/README.md:110-125`).
- **Where.** Ours: `SNAPSHOT_REPO/REVISION` (`frames.py:71-76`), joined by `samples_from` (`:156-197`). Theirs: "all the ground truth Wikipedia articles used by the human annotators" (`arxiv-src:v1/040experiments.tex:9`), text unpublished; the questions were re-verified against live pages "three months after collecting the initial data" (`030dataset.tex:47`).
- **What differs.** The paper's prompts carried the live 2024 pages; ours carry the last pre-2024-09-19 revision drawn with today's templates: 185 of 2,521 articles show a 2025-or-later value (card `:110`), 259 articles used by 213 questions show a `Template:X` stub where a template's output was (`:113`), one deleted article missing on row 540 (`:125`). The card's own check found no gold answer overturned by a leaked value, but 48 questions' table stubs "were not checked one by one" (`:124`).
- **Severity / bound.** `score-changing`, `unbounded`: the reference text does not exist, so the set of Cases whose mark could move cannot be enumerated.

### D3 — the Candidate prompt is ours

- **Declared.** `frames.py:35-37` ("WHY our own Candidate prompt: the paper publishes no oracle template"), README `:36-39`, `test_a_row_renders_its_articles_in_link_order_then_the_question` docstring (`test_local_task_frames.py:92-94`).
- **Where.** Ours: `CASE_TEMPLATE`/`ARTICLE_TEMPLATE` (`frames.py:84-88`). Theirs: none published (`arxiv-src:v1/040experiments.tex:9` is the only description; v3 source identical on this point).
- **What differs.** Everything but the content: wording, article order (ours: link order), article framing (`=== Article N: Title ===`), question last.
- **Severity / bound.** `score-changing`, `unbounded`: no reference bytes to diff against.

### D4 — the judge is gpt-5.4, the paper's was Gemini-Pro-1.5-0514

- **Declared.** `# NAMED DEVIATION: the paper rated with Gemini-Pro-1.5-0514. This Benchmark pins the house judge…` (`benchmarks.py:5037-5039`); README `:48-49`; `frames.py:78-81`.
- **Where.** Ours: `JudgeSpec(model="openrouter/openai/gpt-5.4", params=(("web_search","false"),("max_tokens","4096")))` (`benchmarks.py:5040-5044`), `scorer_kwargs` (`:5035`). Theirs: `arxiv-src:v1/040experiments.tex:13` with the macro at `iclr2025_conference.tex:169`; agreement with humans reported as accuracy 0.96, Cohen's κ 0.889 for that rater.
- **What differs.** The model that reads Figure 6. The prompt bytes, system message and slots are identical (Checks run 10). Our token cap and `web_search=false` have no counterpart in the paper. Reply parsing: ours is `frames.py:124`; the paper's is unpublished.
- **Severity / bound.** `score-changing` by design (spec §2.3), `unbounded`. No paid run on our side can bound it: the bound would need the paper's rater on the same replies, and Gemini-Pro-1.5-0514 is no longer offered by its provider as far as this audit knows (not checked; see Recommended paid runs).
