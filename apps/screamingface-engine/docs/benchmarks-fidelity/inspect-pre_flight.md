# Pre-Flight — Fidelity Record

## Verdict

**`comparable-to-inspect`.** Our headline is plain accuracy over the 300 Cases of [`AirsideLabs/pre-flight-06@439d2d11`](https://huggingface.co/datasets/AirsideLabs/pre-flight-06/tree/439d2d118fed7d9b009c1f87b9eb1205ab94766e). It can sit beside a run of [inspect_evals v0.20.0 `pre_flight`](https://github.com/UKGovernmentBEIS/inspect_evals/tree/v0.20.0/src/inspect_evals/pre_flight) on inspect_ai 0.3.263. Against that reference everything matches: the Cases are the pinned Hub rows in Hub order, with digests equal to the seal; the Candidate input equals the Task's own `multiple_choice()` rendering on all 300; our production aggregate route gives the same 4,500 marks as the Task's own solver plus `choice()`; and the roll-up equals `accuracy()` to four decimals on eight vectors. No deviation, declared or undeclared, was found: `sum of bounds against inspect_evals = 0/300 = 0.0000 ≤ COMPARABLE_TOLERANCE (0.005)`.

The authors' harness is this same Task. [Brooker & Hughes 2026, §4](https://arxiv.org/abs/2607.01829v1) says they ran "the pre_flight task distributed in inspect_evals" at revision `439d2d1`, and `pre_flight.py` is byte-identical from inspect_evals v0.4.0 through v0.14.2 (the release current at the paper's 29 June 2026 snapshot) to v0.20.0. It still is not the same examiner as ours, because the paper's rolling leaderboard was marked by earlier inspect_ai releases. inspect_ai 0.3.242, the release tagged on the snapshot date, marks `ANSWER: C,` (a stray trailing comma) wrong where 0.3.263 marks it right, and that changes 300/300 Cases on that answer sheet. Releases before 0.3.221 also took the first `ANSWER:` line instead of the last and refused lowercase letters. How often this happens depends on how a Candidate formats its reply, so the gap is `unbounded` (Upstream notes). By the rule, `inspect_evals vs original harness = unbounded > 0.005 → comparable-to-inspect`, not `comparable-to-paper`. The paper's GPT-5.5 82.7% headline also leaves open whether two answer keys were corrected (Upstream notes, `2/300`).
