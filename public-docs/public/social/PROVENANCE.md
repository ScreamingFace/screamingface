# Link-preview card

`sf-docs-og-1200x630.png` is the docs link card that `index.html` names in `og:image` and
`twitter:image`. It is 1200×630 RGB PNG and mirrors the navbar brand: the 😱 mark above the
ScreamingFace wordmark, with the `DOCS` label in IBM Plex Mono 500 at 0.14em tracking.

It was rendered from the brand guide's own files (brand.screamingface.ai):

- `assets/mark/downloads/sf-mark-2000.png`, at 240 px
- `assets/logo/sf-wordmark-dark.svg`, at 62 px tall
- background `#05070b`, label `#9a9fa7`

The layout matches the brand guide's `sf-og-1200x630.png` (mark centred, name below). The whole
lockup sits inside the centre 630 px, so apps that crop previews to a square keep all of it.
